# Sun Eater · mead.fi

Лендинг-визитка медоварни Sun Eater. Vite + React + TypeScript + Tailwind CSS 4, на выходе чистая статика в `dist/`.

```bash
npm install      # один раз
npm run dev      # локальная разработка, http://localhost:5173
npm run build    # проверка типов + сборка в dist/
npm run preview  # просмотр собранной версии
```

## Картинки: `public/img/`

| Файл | Где используется |
| --- | --- |
| `logo-light.png` | Логотип в центре Hero (сейчас временный пример, белая версия `logo.png`) |
| `hero-bg.jpg` | Фон Hero |
| `black-currant.jpg` | Этикетка «Mustaherukka» |
| `bilberry-vanilla.jpg` | Этикетка «Mustikka & Vanilja» |
| `cherry.jpg` | Этикетка «Kirsikka» |
| `raspberry.jpg` | Этикетка «Vadelma» (сейчас скрыта) |

Если файла нет или путь пустой, сайт сам показывает плейсхолдер: текстовый логотип, тёмный градиент вместо фона, абстрактную этикетку в цвете вкуса.

Советы по файлам:

- Развёртки этикеток: JPG или WebP шириной около 2400 px, все в одинаковых пропорциях. Пропорции укажи в `lineup.labelAspectRatio` (например `'2 / 1'` для 2400×1200). Если пропорции не совпадут, края картинки обрежутся.
- Логотип: светлый рисунок на прозрачном фоне, лучше SVG (например `logo.svg`, тогда поменяй `logoImage`). Тёмный логотип на белом фоне на тёмном сайте будет выглядеть белой плашкой.
- Фон Hero: JPG или WebP шириной 2400 px, желательно до 400 кБ (влияет на скорость загрузки, LCP).

## Тексты и настройки: `src/data/content.ts`

Всё редактируемое лежит в одном файле:

- `defaultLang`: язык по умолчанию (`'fi'`).
- `email`, `location`: данные в футере.
- `hero.image`, `logoImage`: картинки Hero.
- `lineup.labelAspectRatio`: пропорции развёрток этикеток.
- `hero.useEnglishHeadlineForAllLanguages: true`: английский слоган на обеих версиях.
- `flavors[]`: карточки вкусов, идут колонкой сверху вниз в порядке массива. `enabled: false` скрывает карточку, `image` задаёт этикетку, `accentColor` цвет плейсхолдера и свечения.
- `meta`: заголовок вкладки и описание для поисковиков на двух языках.
- `ageGate`: окно «Oletko vähintään 18-vuotias?» при первом визите. `enabled: false` выключает его. Ответ «да» запоминается в браузере. Чтобы снова увидеть окно при тестировании, открой сайт в приватном окне.

TypeScript проверяет структуру: если пропустить перевод или опечататься в поле, `npm run build` укажет на ошибку.

Тексты карточек согласованы с ограничениями Alkoholilaki § 50 и требованиями ЕС к маркировке. Новые формулировки (особенно про натуральность, безглютеновость, происхождение сырья и акции) перед публикацией стоит перепроверить.
